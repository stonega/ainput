# Project instructions

## Extension version and changelog

- Treat the `version` in `public/manifest.json` as the canonical extension
  version.
- Record every user-visible extension change in `changelogs.md` before
  completing the work.
- Add each change under a version heading that exactly matches the current
  extension version in `public/manifest.json`.
- When the extension version changes, create a new changelog section and keep
  all previous version sections intact.
- Verify the manifest version and changelog version heading remain synchronized
  as part of the final validation.
